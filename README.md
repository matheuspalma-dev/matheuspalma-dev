## Projeto em Destaque

### [OPM — Ouvidoria de Proteção a Menores](https://github.com/matheuspalma-dev/opm-api)
> **Stack:** `Java` • `Spring Boot` • `Spring Security` • `JWT` • `PostgreSQL` • `Docker`

API em desenvolvimento ativo projetada para atender a **rede municipal de ensino** da minha cidade, funcionando como um canal de denúncias 100% anônimas de bullying e cyberbullying nas escolas, com painel de gestão e acompanhamento individualizado para cada ocorrência.

* **Foco técnico e implementação:** Arquitetura REST desenvolvida para privacidade de dados (LGPD) para garantir o anonimato real dos denunciantes, controle de acesso stateless para gestores utilizando **Spring Security e JWT**, além da modelagem relacional do banco de dados e containerização com **Docker**.
